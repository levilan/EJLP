# Phase 0 練習包 — 手機版設計規格

版本 0.1，2026-09-12。定位：**現有練習包改為響應式，手機也能做完整每日量（240 題／1.5–2 小時）**。搭配可運作原型 `phase0-mobile-prototype.html`（殼＋示範資料，之後接題庫 JSON）。

---

## 1. 設計前提

桌機版是「分頁＋整頁題目」的結構，直接縮到手機會有三個問題：

| 問題 | 桌機版現況 | 手機版對策 |
|---|---|---|
| 一次 240 題，手機上單次坐不完 | 一整頁滾動 | 拆成 11 個區塊，每區塊可獨立完成；離開時保留進度，回來從中斷處繼續 |
| 打字成本高 | 填空／改錯／重組／聽寫／中譯英全部鍵盤輸入 | 改錯改成「點錯字→輸入正確字」、重組改成「點字塊拼句」、單字複習預設四選一；只有真正需要造句的題型（中譯英、聽寫、寫作）保留鍵盤 |
| 沒有「還剩多少」的感覺 | 依分頁計數 | 首頁 11 段進度條 + 預估剩餘分鐘；每題畫面頂端顯示「第 i／N 題」 |

**核心原則：一題一畫面、操作在拇指區、隨時可中斷。**

---

## 2. 資訊架構

```
底部導覽（4 個）
├─ 今日      首頁：Day N、11 區塊清單、繼續按鈕
├─ 進度      56 天格子（完成率）＋週檢測分數
├─ 檢測      入門診斷／週檢測／結業／單字保留率／CEFR 自評／外部驗證紀錄
└─ 設定      語音、語速、每日量、複習模式、匯入題庫、匯出／重置進度
```

區塊執行畫面（Runner）是全螢幕覆蓋，不顯示底部導覽，避免誤觸。

---

## 3. 畫面規格

### 3.1 今日（首頁）

```
┌──────────────────────────────┐
│ Day 14        第 2 週 第 7 天 │  ← 大字 Day，右側週資訊
│ 9 月 12 日  家人與所有格       │
│ ▮▮▮▮▮▮▯▯▯▯▯  6/11 區塊  約 58 分鐘剩 │  ← 11 段進度條（每段＝一個區塊）
│                              │
│ [ 繼續：填空 第 23 題 ]        │  ← 主按鈕，回到上次中斷處
│                              │
│ 新字        25   已完成 ✓      │
│ 單字複習    60   已完成 ✓      │
│ 選擇        50   已完成 ✓      │
│ 填空        50   22/50   進行中 │
│ 中譯英      20   —      15 分  │
│ 改錯        15   —      10 分  │
│ ...                          │
│ ‹ 前一天            後一天 ›  │
├──────────────────────────────┤
│  今日   進度   檢測   設定     │
└──────────────────────────────┘
```

- 依裝置日期自動定位到今天（Day 1 = 2026-08-30，Day N = 差距 +1，範圍 1–56）。
- 每列：區塊名、題數、狀態（未開始顯示預估分鐘；進行中顯示 i/N；完成顯示 ✓ 與正確率）。
- 「繼續」永遠指向**第一個未完成區塊的下一題**。
- 週 Day 7 的區塊是總複習彙整，結構相同，標題加「總複習」。

### 3.2 區塊執行（Runner）

```
┌──────────────────────────────┐
│ ✕  填空                 23/50 │
│ ━━━━━━━━━━━━━━━━━━━━━━░░░░░░ │  ← 本區塊進度
│                              │
│  My parents ______ a small   │
│  car.                        │
│                              │
│  ┌──────────────────────┐    │
│  │ have                  │    │  ← 16px 以上字級，避免 iOS 自動放大
│  └──────────────────────┘    │
│  提示：have / has             │
│                              │
│                              │
├──────────────────────────────┤
│  [ 跳過 ]      [ 檢查答案 ]    │  ← 固定底部，拇指區
└──────────────────────────────┘
```

回饋狀態：

```
│  ✓ 正確                      │   或   │  ✗ 正確答案：has               │
│  第三人稱單數用 has。          │        │  第三人稱單數用 has。          │
├──────────────────────────────┤        ├──────────────────────────────┤
│               [ 下一題 ]      │        │  [ 加入錯題 ]     [ 下一題 ]   │
```

- 答對後 **不自動跳題**（使用者要能看解析），但按鈕焦點直接在「下一題」，Enter／Go 鍵即前進。
- 「跳過」記為未作答，不計入正確率，區塊結束時提示「有 N 題跳過，要回頭做嗎？」。
- 離開（✕）立即保存到「本區塊第幾題」。
- 完成畫面：正確率、用時、錯題清單（可展開重看）、「回今日」。

### 3.3 各題型互動（手機專用調整）

| 題型 | 每日量 | 手機互動 | 批改 |
|---|---|---|---|
| 新字 | 25 | 卡片：單字、詞性、中文、例句、🔊。按「認識」／「再看一次」；「再看一次」的字會在本區塊尾端重出一次 | 不批改 |
| 單字複習 | 60 | 預設四選一（中→英、英→中混合）；設定可切「打字」模式 | 選擇：精確；打字：正規化比對 |
| 選擇 | 50 | 四個全寬按鈕，每個 ≥ 48px 高 | 精確 |
| 填空 | 50 | 單行輸入；答錯一次後顯示提示 | 正規化＋縮寫雙向展開 |
| 中譯英 | 20 | 多行輸入；答錯時並列顯示參考答案，提供「我覺得算對」自評鍵 | 正規化比對多個參考答案；自評覆寫 |
| 改錯 | 15 | 句子拆成可點字塊；點錯字→彈出輸入框（預填該字）→檢查 | 位置＋替換字都對才算對；位置錯先提示 |
| 重組 | 15 | 上方為答案槽，下方為打散字塊；點下方加入、點上方移除；長按無其他功能 | 拼出句子後正規化比對 |
| 閱讀 | 4 篇 20 題 | 短文放在可收合的頂部面板（預設展開，作答時自動收合為「看短文」列，點開為底部抽屜） | 精確 |
| 聽寫 | 10 | 🔊 播放、🐢 慢速（0.7×）、輸入；可重播無限次 | 正規化＋縮寫展開 |
| 口說 | 20 | 題目＋🔊 範例；⏺ 錄音（MediaRecorder）→ 回放；自評三檔「不順／還可以／流利」 | 自評；有 Web Speech API 時顯示辨識文字作參考 |
| 寫作 | 4 | 多行輸入、字數計、草稿即時保存；按「完成」後顯示範例 | 不批改；可標記「已請人改」 |

**正規化規則（沿用桌機版並補強）**：小寫、去頭尾空白、多空白合一、去句尾標點、apostrophe 統一（’→'）、縮寫雙向展開（isn't/is not、I'm/I am、can't/cannot、don't/do not、doesn't、didn't、aren't、wasn't、weren't、it's、he's、she's、they're、we're、you're、I've、there's、that's、what's、where's、let's、won't/will not、I'd）。

### 3.4 進度

- 8 列 × 7 格 = 56 天，每格以填充比例表示完成率，今天加外框，未來日子淡色。
- 下方列出各週檢測分數與門檻判定（≥80 通過／60–79 做 Day 7 再考／<60 重做 Day 2–4）。
- 點某一天 → 切換首頁到那一天（可補做或回顧）。

### 3.5 檢測

- 清單：入門診斷（Day 0）、週檢測（每週）、結業測驗（Day 56）、單字保留率（每 2 週）、CEFR 自評（Day 0/28/56）、外部驗證紀錄。
- 每項顯示「建議時間」與最近一次分數。
- **考試模式**：與 Runner 同一元件，`exam: true` 時不即時顯示對錯、不能跳回、只有「下一題」；交卷後顯示總分與**依文法點的正確率**，<70% 的文法點標紅。
- 週檢測入口自動對應當週；未到 Day 6 顯示「建議 Day 6 後再考」但不鎖。
- 外部驗證：表單記錄 EF SET / Cambridge / British Council 的日期、等級、分數。
- 進入 Phase 1 條件檢核表：四條件各顯示達成／未達成。

### 3.6 設定

| 項目 | 選項 | 說明 |
|---|---|---|
| 朗讀語音 | 系統英文語音清單 | 自動挑最自然的（Samantha / Daniel / Karen / Google UK 等優先），可手動換 |
| 語速 | 0.7–1.2 | 聽寫的慢速鍵固定 0.7× |
| 每日量 | 100% / 75% / 50% | **對應第 3 週檢視決策**：完成率低於 60% 時降到 75% 或 50%，每區塊題數等比縮減（取前 N 題，其餘標「加練」可自選做） |
| 單字複習模式 | 四選一 / 打字 | |
| 匯入題庫 | 選檔或貼上 JSON | 格式見第 5 節 |
| 匯出進度 | 下載 JSON | 換裝置或備份 |
| 重置 | 二次確認 | |

## 4. 版面與視覺

- **寬度**：≤ 600px 為手機版面；> 600px 置中單欄（最大 560px），同一份檔案桌機也可用。
- **安全區**：底部按鈕列與導覽列加 `env(safe-area-inset-bottom)`；高度用 `100dvh`。
- **觸控**：所有可點目標 ≥ 44×44px；輸入框字級 ≥ 16px（避免 iOS 聚焦時縮放）；`touch-action: manipulation` 消除 300ms 延遲。
- **字體**：英文題目用 Atkinson Hyperlegible（I／l／1、O／0 區分明確，適合初學者），中文用系統字（PingFang / Noto Sans TC）。
- **色彩**：作業簿式——紙面淺灰綠底、深墨綠字、藍墨水主按鈕、黃色螢光筆標示作答中／已選、紅筆錯、綠筆對。避免整頁卡片化，首頁用列表與細線。
- **動態**：只有「答案揭曉」有一次短動畫；`prefers-reduced-motion` 時全關。
- **記憶點**：11 段進度條，首頁與每題畫面頂部都看得到。

## 5. 資料格式（題庫 JSON）

桌機版題庫需匯出成以下結構，原型會直接吃。

```json
{
  "meta": { "day1": "2026-08-30", "days": 56, "version": "phase0-1.0" },
  "days": {
    "14": {
      "week": 2, "dayOfWeek": 7, "topic": "家人與所有格",
      "review": true,
      "blocks": {
        "vocab_new":    [{ "w": "aunt", "pos": "n.", "zh": "阿姨；姑姑", "ex": "My aunt lives in Taichung.", "review": false }],
        "vocab_review": [{ "q": "眼鏡", "a": "glasses", "opts": ["glasses","classes","glass","grass"], "dir": "zh2en" }],
        "mc":           [{ "q": "This is my brother. ___ name is Leo.", "opts": ["His","Her","He","Him"], "a": 0, "gp": "所有格", "why": "brother 是男性，所有格用 his。" }],
        "fill":         [{ "q": "My parents ___ a small car.", "a": ["have"], "hint": "have / has", "gp": "have-has", "why": "..." }],
        "translate":    [{ "zh": "我爸爸有一台電腦。", "a": ["My father has a computer.", "My dad has a computer."], "gp": "have-has" }],
        "error":        [{ "s": "My sister have a red bag.", "wrong": 2, "fix": "has", "gp": "have-has", "why": "..." }],
        "reorder":      [{ "words": ["is","This","my","aunt."], "a": "This is my aunt." }],
        "reading":      [{ "title": "My family", "text": "...", "qs": [{ "q": "...", "opts": ["..."], "a": 1 }] }],
        "dictation":    [{ "s": "My uncle has a big house." }],
        "speaking":     [{ "prompt": "Tell me about your family.", "model": "I have a big family. ..." }],
        "writing":      [{ "prompt": "寫 3 句話介紹你的家人。", "minWords": 15, "sample": "..." }]
      }
    }
  },
  "tests": {
    "diagnostic": { "items": [ { "type": "mc", "q": "...", "opts": [], "a": 0, "gp": "be 動詞" } ] },
    "weekly":     { "1": { "items": [] } },
    "final":      { "items": [] },
    "retention":  { "pool": [ { "w": "aunt", "zh": "阿姨", "learnedDay": 9 } ] },
    "cefr":       { "a1": ["能用簡單句自我介紹", "..."], "a2": ["..."] }
  }
}
```

- `error.wrong` 是以空白切詞後的索引（從 0 起），標點視為附著在字上（`bag.`）。
- `fill.a`、`translate.a` 一律陣列，容納多個正確寫法；縮寫不用另列，批改會展開。
- `gp`（grammar point）欄位在檢測結果分析必填；練習題選填。

**進度 JSON（匯出／匯入）**：

```json
{
  "version": 1,
  "settings": { "voice": "Samantha", "rate": 0.95, "amount": 100, "reviewMode": "choice" },
  "progress": { "14": { "fill": { "done": 22, "correct": 18, "skipped": [5, 11], "answers": { "0": "have" } } } },
  "drafts":   { "14": { "writing": { "0": "I have ..." } } },
  "tests":    { "weekly": { "2": { "score": 84, "byGp": { "所有格": 90, "have-has": 75 }, "date": "2026-09-12" } } },
  "external": [ { "provider": "EF SET", "date": "2026-08-30", "level": "A1", "score": 21 } ]
}
```

## 6. 儲存與離線

- 正式部署：進度／草稿／設定存 `localStorage`（與桌機版相同 key 前綴 `p0:`，讓兩邊可互相匯入）。原型檔在 Claude 環境內無法用 localStorage，改為記憶體＋匯出 JSON；`Store` 物件只有 `get/set/remove` 三個方法，部署時換成 localStorage 版本即可。
- 題庫 JSON 約 2–3 MB，首次載入後快取（Cache Storage）；建議加 `manifest.json` + 最小 service worker 做成 PWA，加到主畫面後全離線可用。
- 桌機 ↔ 手機同步：第一版用匯出／匯入 JSON；若之後要自動同步，進度 JSON 很小，可推到任何 KV（例如 n8n webhook 寫 Ragic）。

## 7. 語音

- 朗讀：`speechSynthesis`。iOS 需在使用者手勢內第一次呼叫；`voiceschanged` 事件後再填語音清單；語速預設 0.95。
- 錄音：`MediaRecorder` + `getUserMedia`，iOS Safari 14.5+ 支援；不支援時隱藏錄音鍵只留自評。
- 語音辨識：`webkitSpeechRecognition` 只有 Chrome/Android 穩定，做為口說的參考文字，不做評分依據。

---

## 8. 從桌機版遷移的步驟

1. 桌機版加「匯出題庫 JSON」（依第 5 節結構），一次性產出全 56 天＋測驗題庫。
2. 手機版原型在設定頁匯入該 JSON，確認 11 種題型都能跑（示範資料已覆蓋每一型）。
3. 把 `Store` 換成 localStorage 版本，加 manifest 與 service worker。
4. 每日 23:00 推播內容加上手機版連結。
5. 用 1 週後決定桌機版是否退役：若手機版能穩定做完 240 題，桌機版只保留檢測的長文閱讀。

# 英日雙語練習包

手機優先的英文（A1→A2）＋日文（JLPT N5→N1）自學練習網站。

**直接使用**：手機打開 **https://levilan.github.io/EJLP/** ，加入主畫面，用起來就像 App；載入一次後離線也能開。

## 內容

**英文：Phase 0 地基期，Day 1–61（Day 1 = 2026-08-30）**
- 第 1–7 週：be 動詞 → 所有格與 have/has → 現在簡單式 → there is/are 與方位 → 可數不可數與 some/any → 過去式 → be going to 與 can
- 第 8 週：總複習與自我檢測；Day 56 休息
- 補充週 Day 57–61：現在進行式（肯定、否定、問句、與現在簡單式對比）
- 每天 11 個區塊約 240 題：新字、單字複習、選擇、填空、中譯英、改錯、重組、閱讀、聽寫、口說、寫作；每週第 7 天是該週總複習
- 每週文法說明可在「今日」頁展開
- 檢測：入門診斷、週檢測 1–7＋補充週（≥80% 進下一週）、結業測驗、單字保留率、CEFR 自評、外部驗證紀錄，以及進入 Phase 1 的條件檢核

**日文：JLPT N5–N1，58 課（Day 1 = 2026-10-19）**
- N5 12 課（每課 1 週）→ N4 12 課（每課 2 週）→ JLPT N4 2027/7/4 → N3 10 課（每課 2 週）→ JLPT N3 2027/12/5 → N2 12 課（每課 3 週）→ JLPT N2 2028/12/3
- 每課：單字 20、文法 3、選擇 12、填空 10、讀解 1 篇 4 題、聽解 4 題、跟讀 6 句、作文 1 題、單字卡
- 「今日」頁依日期顯示當天的課與任務（第 1 週新學、第 2 週鞏固、第 3 週延伸、考前衝刺）
- 錯題自動進本課錯題本，重做答對就移除
- 五級模擬測驗各 40 題，依合格線與每區 ≥40% 判定
- 讀解、例句、跟讀、聽解稿都有振假名，點字可查讀音與意思；讀音題不加振假名，避免洩題

**分級閱讀**
- 英文 A1：*The House of Usher*、*The Gift*、*The Lion and the Mouse*、*The Ugly Duckling*；A2：*The Necklace*、*The Monkey's Paw*
- 日文 N5：《桃太郎》《鶴の恩返し》《浦島太郎》《笠地蔵》；N4：《蜘蛛の糸》《注文の多い料理店》
- 皆為公有領域作品的原創改寫
- 閱讀／收聽（逐句朗讀＋高亮）／翻譯三種模式；點單字看音標、中文、日文或英文與發音
- 生字本依間隔重複排程（1、2、4、7、15、30 天）；每日 10 分鐘閱讀目標

## 使用說明

- 語音用瀏覽器內建朗讀。日文需先安裝日文語音：iPhone 設定 → 輔助使用 → 朗讀內容 → 聲音 → 日文
- 進度存在瀏覽器裡；換裝置前到「設定 → 匯出進度」

## 目錄

```
index.html  app.js  app.css  sw.js     網站本體（sw.js 提供離線快取）
data/
  en.json                              英文 Day 1–61 與檢測題庫
  ja/index.json, ja/N5.json … N1.json  JLPT 課程與模擬測驗（含振假名詞塊）
  library.json                         分級讀物
  gloss.json                           點字查詢詞彙表
source/                                原始題庫（Phase 0 練習包、JLPT 練習帳）
generators/                            產生 data/ 的程式
docs/                                  設計規格
legacy/                                早期原型
```

## 重新產生資料

```bash
pip install -r requirements.txt
python generators/build_all.py
```

本機預覽要用 HTTP 伺服器（題庫用 fetch 載入），例如 `python -m http.server`，再開 http://localhost:8000 。

## 已知限制

- 聽力是瀏覽器 TTS，不是真人語音；Phase 1 起需搭配真人素材
- 日文每課的單字是核心字，不是該級全部字彙；要搭配 Anki 與教材
- 振假名由斷詞程式自動標注，少數專有名詞讀音可能不準
- 2027 年以後的 JLPT 考期為推估，報名前以 LTTC 公告為準
